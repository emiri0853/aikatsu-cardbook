# アンコール カード帳

アイカツ！アンコールのカード所持数・求／譲・QR読み込み履歴を管理する非公式Webアプリです。

## 公開手順（GitHub Pages）

1. このフォルダの中身をリポジトリのルートに置いて push
2. Settings → Pages → Branch を `main` / `(root)` にして Save
3. `https://<ユーザー名>.github.io/<リポジトリ名>/` で開く

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| index.html | アプリ本体 |
| cards.js | カードの一覧（新カードは自動で追加されます） |
| .github/workflows/update-cards.yml | 毎朝6時に公式カードリストを確認して、新カードを cards.js に追加 |
| manifest.webmanifest | ホーム画面追加（PWA）の設定 |
| sw.js | オフライン用キャッシュ |
| icons/ | アプリアイコン |

## データについて

- 所持数・求譲・履歴はブラウザの localStorage、写真は IndexedDB に保存されます（サーバーには送信しません）
- 機種変更やブラウザのデータ削除に備えて、⚙ → バックアップ で JSON を保存してください

## 新カードの自動追加

- 毎朝6時（日本時間）に GitHub Actions が公式カードリストを確認し、cards.js に無いカード番号とレアリティを追加します
- 既存のカードの情報は変更・削除しません。所持数などのデータもそのままです
- 今すぐ確認したいときは、Actions タブ →「新カードの自動追加」→「Run workflow」
- 自動で入るのは番号とレアリティだけです。カード名は公式サイトの画像の中にしかないため、名前は後から追加してください
- リポジトリに60日間更新がないと、GitHub の仕様で自動実行が止まることがあります。その場合は Actions タブで再度有効にしてください

## 注意

- 公式のカード画像はリポジトリに含めないでください。アプリは公式サイト上の画像を直接読み込んで表示するだけで、画像ファイルは保存・同梱しません（絞り込み →「公式画像を使う」でオフにできます）
- 本アプリはバンダイ公式とは関係ありません
